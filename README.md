# FleshOut — AI 小说阅读、改写与创作工作台

> 本地优先的开源 AI 写作工具：把长篇小说阅读、剧情大纲设计、AI 改写、写法卡片与版本管理放进同一个工作台。

FleshOut 是一个运行在本机的网页应用，适合网络小说读者、写作者和编辑使用。你可以上传 TXT 小说，以舒适的排版阅读；选中任意段落，让 DeepSeek 按你的要求改写；在改写前先设计剧情大纲，再用 AI 提取全文的角色设定与世界观，让每一次改写都保持故事一致。所有数据只保存在你自己的电脑上，API Key 不会离开你的浏览器。

你可以这样「玩坏」你的书单：

### 🏔️ 仙侠玄幻：改写命运，重写大道

- 《剑来》：如果陈平安在泥瓶巷时就获得「躺平系统」，选择安逸度日，故事会走向何方？或者，让你自己穿越成陈平安，用现代思维在剑气长城开「连锁书铺」，又会是怎样一番景象？
- 《诡秘之主》：如果克莱恩在周明瑞时期没有选择占卜家途径，而是成为「律师」或「罪犯」，序列之路会如何颠覆？或者，把故事背景从蒸汽朋克的贝克兰德换成现代都市写字楼，又能碰撞出怎样的火花？
- 《玄鉴仙族》：既然主角是「家族」本身，那就「空降」一个你设计的全新角色加入李家，看他如何影响家族命运；或者开启一条「如果当初没有选择修仙」的 IF 线，看看角色们的平凡人生。

### 🔍 悬疑灵异：重置谜题，另类破局

- 《十日终焉》：你可以作为「第十一个玩家」被投入游戏，带着自己的知识体系和性格去破解迷局；或者直接更改一条核心「规则」，观察整个故事会如何崩坏与重建。
- 《国民法医》：主角江远可以放弃法医系统，转而绑定「罪犯模拟器」，从反派视角重新审视所有案件；或者让「法医系统」本身出错，给出完全相反的鉴定结论，制造全新的故事冲突。

### 👑 历史权谋：篡改历史，另类建国

- 《黜龙》：既然「龙」是垄断元气的权贵阶层，就可以设定一个「屠龙者」角色，直接颠覆整个力量体系；或者让主角放弃争霸，选择「科技建国」，用现代技术改变那个架空世界。
- 《赘婿》：如果宁毅没有选择帮助武朝，而是决定自己称帝，剧情会如何翻天覆地？又或者，让一个现代女权主义者穿越成苏檀儿，会和宁毅产生怎样有趣的观念碰撞？

### 💼 都市重生：换条赛道，另一种开挂

- 《我真没想重生啊》：让主角陈汉升放弃商场，转战娱乐圈或学术圈会怎样？甚至可以设计「重生 + 系统」的双重金手指，看他如何用先知和系统叠加开挂。

### 🎲 其他题材，无限可能

- 如果《斗破苍穹》的萧炎没有失去斗气，他的成长之路会如何不同？
- 如果《全职高手》的叶修没有退役，荣耀联盟的历史又该如何改写？

FleshOut 能做的，远不止「改写」这么简单——它像一个故事的平行宇宙发生器：

- **做自己的编剧**：「如果主角是我……」这个念头，现在可以成真了。
- **深度二创**：让你钟爱的角色和世界观，在你的指令下衍生出全新的故事线。
- **灵感试验场**：在动笔前，用 AI 快速验证你的每一个「疯狂」想法。

还在为心爱的小说意难平？或者想看看自己的脑洞能走多远？FleshOut，让你的每一个「如果」，都成为一个新的故事起点。

## 功能特性

- **沉浸式阅读**：支持 TXT / Markdown / HTML 三种渲染模式，字体、字号、行距、文字与背景颜色均可调；约 10 万字自动分段渲染，长文不卡顿。
- **AI 改写**：基于 DeepSeek，可选中段落或整节改写；支持多条系统级提示词、温度、最大输出、思考模式与强度（low / high / max）配置。
- **大纲设计**：针对选段生成剧情大纲思路——情节目标、冲突递进、人物动机、伏笔埋设/回收、情绪节奏、场景调度，并可直接带入改写指令。
- **写法卡片**：让 AI 分析选中文本的风格特点并生成卡片，创作时随时参考，沉淀自己的写作风格库。
- **附属信息**：维护故事背景、角色设定、情节发展；可手工编辑，也可让 AI 从当前版本全文提取（大文本自动分块、并发合并），改写时自动携带，保持世界观、人物与情节一致。
- **版本管理**：每次改写自动保存为独立版本，支持版本对比，随时回看每一次改动。
- **多用户**：本地账号系统，密码仅存哈希，各用户数据完全隔离。
- **本地优先**：所有书籍、配置与日志均存为本地 JSON 文件，不依赖外部数据库；`data/` 目录不会提交到仓库。

## 快速开始

需要 **Node.js 18+**。

```bash
npm install
npm start
```

打开 <http://localhost:3000>。开发模式（文件变更自动重启）：

```bash
npm run dev
```

## 配置 DeepSeek

登录后在「接口设置」中配置：

- API Key
- Base URL（默认 `https://api.deepseek.com`）
- 模型（默认 `deepseek-v4-flash`）
- 温度、最大输出、思考模式与思考强度
- 多条改写系统级提示词（比如「破甲」，你懂的）
- 附属信息提取提示词（System、故事背景、角色设定、情节发展可分别配置）

## 技术栈

- 后端：Node.js + Express
- 前端：原生 HTML / CSS / JavaScript（无前端框架依赖）
- 存储：本地 JSON 文件（无数据库依赖）

## 目录结构

```text
.
├── server.js            # Express 服务与全部 API
├── public/              # 前端页面、样式与脚本
│   ├── index.html
│   ├── styles.css
│   └── app.js
├── data/                # 运行数据（用户、书籍、配置，已被 gitignore）
├── package.json
└── README.md
```

## 数据与隐私

- 所有数据保存在 `data/` 目录，已被 `.gitignore` 排除，不会进入版本库。
- 密码仅保存哈希值；用户会话保存在本地。
- DeepSeek API Key 由你自行配置，只保存在本机数据中，不会出现在代码或仓库里。
